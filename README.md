# CK Auto

Web prototype of CK Auto, an app for selling Bingwa Sokoni data deals and free SMS bundles.

## Run it
Open `index.html` in a browser, or publish it with GitHub Pages:
1. Create a new repository on GitHub.
2. Upload `index.html`, `README.md` and `.nojekyll`.
3. Go to Settings, then Pages, choose branch `main` and folder `/ (root)`, and save.
4. Your site appears at `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

## What is simulated
USSD screens, SMS reading and sending, and M-Pesa prompts are simulated in this prototype.
The Android APK will do these for real. Accounts are saved only in the browser.
